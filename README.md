# 🏛️ AI 기반 지역별 맞춤 돌봄 정책 효과 시뮬레이션

초고령사회 진입 및 1인 가구 증가에 대응하여, 지역별 인구·복지 데이터를 기반으로 고독사 및 돌봄 공백 위험도를 예측하고 예산·인력 투입 시나리오별 정책 효과를 사전에 검증하는 웹 대시보드입니다.

## 📂 프로젝트 구조
- `data/`: 서울시 25개 자치구 연령별 인구 통계 원본(`raw`) 및 전처리 완료 데이터(`processed`)
- `notebooks/`: 데이터 전처리(`01`), 탐색적 데이터 분석(`02`), AI 모델 학습(`03`) 코드
- `model/`: 학습된 Random Forest 기반 위험도·정책 효과 예측 모델(`.joblib`)
- `app.py`: Streamlit 및 Folium 기반 인터랙티브 시뮬레이션 대시보드
